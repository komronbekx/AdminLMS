# AdminLMS

AdminLMS — o‘quv platformasi (LMS) uchun yaratilgan **admin panel**. Loyiha Django asosida qurilgan bo‘lib, kurslar, darslar, foydalanuvchilar va boshqa ma’lumotlarni boshqarish uchun qulay admin interfeys taqdim etadi.

---

## Xususiyatlari

- Django Admin orqali to‘liq boshqaruv
- Kurslar va darslar uchun CRUD
- Foydalanuvchilarni boshqarish
- Talabalar ro‘yxati
- Kategoriyalarni boshqarish
- Admin layout customizatsiyasi (logo, title, color)
